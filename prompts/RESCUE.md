# 오류가 났을 때

[시험 첫 화면](../README.md) · [전체 문서 지도](../docs/INDEX.md)

제출 확정 전에만 사용한다. 오류 메시지와 관련 파일은 제공 환경 안에서만 공유한다. 아래 내용과 함께 재현 입력, 기대 결과, 실제 결과를 아는 만큼 전달한다.

```text
방금 실패한 동작의 가장 작은 재현 사례부터 확인해줘.
첫 원인과 뒤따른 오류를 구분하고, 원인 가설 하나를 확인한 후 최소 수정해줘.
이미 시도한 수정과 같은 시도를 근거 없이 반복하지 마.
원인을 바꾸는 수정과 관계없는 리팩터링·새 기능은 이번 수정에서 제외해줘.

수정 후 실패했던 사례와 관련된 정상 사례를 실행해 결과를 알려줘.
남은 시간에 해결이 어렵다면 필수 목적을 유지할 단순한 대안을 제시해줘.
플랫폼 차단·모델·감독 연결 문제라면 우회하지 말고
발생 시각, 단계, 직전 동작, 오류 문구로 신고할 내용을 정리해줘.
```

Browser 연결 실패라면 서버 오류·실행 유지 → 실제 포트 → `0.0.0.0` 바인딩 → 경로 순으로 본다. 서버를 실행한 터미널을 닫으면 서비스가 종료될 수 있다.

승인 대기는 내용을 확인해 선택하고, 실행 중이면 같은 요청을 반복하지 않는다. 한 영역만 멈췄다면 표시된 **이 영역 다시 불러오기**, 터미널 문제는 **다시 연결**을 먼저 사용한다. CPU/RAM과 본인이 시작한 작업을 확인하되 전체 프로세스를 종료하지 않는다. 저장 충돌은 양쪽 내용을 비교해 **외부 변경 불러오기 / 현재 내용으로 저장**을 선택하고 `저장됨`을 확인한다. [화면별 복구표](../docs/EXAM-PLAYBOOK.md)
